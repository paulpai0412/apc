水泥磨迴路的穩健模型預測控制
Robust Model Predictive Control of Cement Mill Circuits

以有限脈衝響應（FIR）模型、移動視窗估測與「軟約束」MPC，解決水泥球磨迴路的模型失配與慢速品質量測問題。

01一分鐘概覽

這本論文回答一個工業控制問題：當水泥磨的線性模型注定不準、產品品質每小時才量測一次時，MPC 要怎麼設計才不會「越控越亂」？

問題

閉路球磨迴路具非線性與強交互作用，進料（熟料、石膏、粉煤灰）成分與易磨性波動大，由簡單測試建立的模型存在大量不確定性，傳統控制效能差（摘要，PDF p.5）。

方法

以 FIR 脈衝響應模型建立帶輸入／輸入速率限制的 ℓ₂ 預測控制器，轉成凸二次規劃（QP）用內點法求解；再加上設定點周圍的「軟輸出限制」（死區）提升對模型失配的穩健性（Ch.3）。

驗證平台

MATLAB SISO／2×2 MIMO 模擬 → FLSmidth 的 ECS/CEMulator 高保真水泥廠模擬器 → UltraTech Cement Arakkonam 廠線上實測（與既有模糊邏輯控制器比較）。

主要結果（作者宣稱）

CEMulator 上操縱量變動較傳統 MPC 減少約 50%（正文可查數據為進料標準差 −26%、分離器轉速 −96%）；實廠細度標準差改善約 23%。細節與保留意見見第 6、8 節。

作者還提出一條處理「小時級品質取樣」的經驗法則：把控制器模型中細度相關路徑的延遲額外加上約半個品質取樣週期（每小時取樣 → +30 min），即可沿用原本調好的控制器權重（Ch.7）。

02製程與控制問題（Ch.5）

水泥成品粉磨是「球磨機＋動態分級機」組成的閉路迴路。研磨後的物料由斗式提升機送往分級機：細粉成為成品，粗粒被拒料回磨機再磨。典型吞吐量約 120–150 t/h（Ch.5，紙本 pp.110–116／PDF pp.127–133）。

控制結構：2×2 MIMO，不是兩個獨立迴路

論文的控制器是完整的 2×2 多變數架構——兩個操縱量一起影響兩個受控量，存在不可忽略的交互作用（耦合）。「進料管負荷、分離器管細度」只是工程直覺，不是論文的控制結構。

03三個方法支柱（Ch.3）

全論文的數學核心是：用 FIR 模型做預測、用估測器補償未知擾動、用軟輸出限制換取穩健性。三者最後都收斂到同一個形式——凸二次規劃（QP），以內點法求解。

3.1 FIR 模型與預測控制器

穩定製程可用有限脈衝響應（FIR）模型表示（式 3.5，紙本 p.69）：輸出是過去 n 個輸入的加權和，權重 Hi 即馬可夫參數，bk 是估測器提供的偏差項。FIR 的優點：可直接由工廠測試資料估計、只需要安定時間資訊（不需事先知道階次與延遲）、天然適合「缺漏量測」（如小時級化驗值）；代價是僅適用於穩定製程。

式 (3.5)、(3.6a) zk = bk + Σi=1..n Hi·uk−i
min φ = ½·Σ‖zk+1 − rk+1‖²Qz + ½·Σ‖Δuk‖²S， 受限於 umin ≤ uk ≤ umax、Δumin ≤ Δuk ≤ Δumax

預測視界與控制視界取相同長度 N，並刻意取夠長，使視界末端的邊界效應不影響前端解。每個取樣時刻只執行最優序列的第一步（receding horizon），下一步重新最佳化（圖 3.3）。

3.2 估測器：簡易偏差估測 vs. 移動視窗估測（MHE）

為了消除穩態誤差，回授環路需要積分作用。論文用了兩種做法，兩者不可混為一談：

估測器做法角色
簡易估測器（§3.3.3，式 3.9） 把 FIR 模型寫成差分形式，將「模型預測與實際輸出之差」ek 累加成偏差項 b̂k = b̂k−1 + ek，等效於假設擾動是「定值輸出擾動」。 計算便宜；後續 Soft MPC 與所有水泥磨實驗實際採用者（§3.7 明載：因 MHE 需同時解估測＋控制兩個最佳化，計算量大）。
移動視窗估測 MHE（§3.5，式 3.14） 在長度 Ne 的歷史視窗上，把未知擾動序列 dk（拆成慢變水位 d̄＋快變雜訊 w）當決策變數，正規化擬合歷史量測，可對擾動加幅值／速率限制。 理論貢獻與 SISO 模擬驗證（§3.6）；未用於後續 Soft MPC 與工廠實驗。

3.3 軟約束 MPC（全書核心）

傳統 MPC 對「輸出偏離設定點」一律二次懲罰，因此會對量測雜訊與模型誤差過度反應，造成操縱量頻繁抖動。作者的解法：在設定點周圍劃一條軟帶（dead zone），帶內誤差只給極小懲罰，帶外才用二次＋線性懲罰重罰（式 3.22，紙本 p.91）：

式 (3.22) min φ = ½·Σ‖zk+1 − rk+1‖²Qz + ½·Σ‖Δuk‖²S + ½·Σ‖ηk‖²S + Σ s′·ηk
s.t. zk = bk + Σ Hiuk−i；u、Δu 硬限制；zk ≤ zmax,k + ηk；zk ≥ zmin,k − ηk；ηk ≥ 0

鬆弛變數 η 讓輸出「可以」越界，但越界要付出二次＋線性代價；帶內保留一個很小的二次懲罰，以維持穩態無偏移（offset-free）。整個問題仍可整理成標準凸 QP（推導見附錄 A.3，式 A.26–A.37：預測寫成 Z = c + ΓU，Hessian H = Γ′QzΓ + Λ′SΛ），用內點法求解（附錄 D）。

軟帶寬度經驗法則（§3.7.2，紙本 pp.93–94）：太寬 → 反應遲鈍甚至穩態偏差；太窄 → 退化成傳統 MPC、失去穩健性。作者建議依量測＋製程雜訊變異數選取（原文示例：雜訊變異數 σ²=2.5 時取軟限 ±2；並建議軟限約取 0.8–0.9 倍雜訊變異數 N——此句原文敘述簡略，引用時建議對照圖 3.30）。

07亮點章節：慢速品質量測的延遲補償（Ch.7）

細度每小時才由自動取樣器取樣、化驗後輸入系統，而提升機負荷是連續量測。直接用「1 分鐘級資料」建立的模型控制「每小時更新」的細度，效能明顯退化。本章全部為 CEMulator 模擬結果，非實廠測試。

問題（名義模型直接用於小時級量測）

  • 需反覆試誤重新調參（權重 Qz、執行器動作權重 S 等），作者報告約 3–4 次才穩定
  • 提升機負荷約 3.5 小時才收斂
  • 細度存在穩態偏差，操縱量振盪

作者的解法：半取樣延遲規則

  • 只把控制器模型中細度那一列的兩條路徑，額外加上約半個品質取樣週期的延遲（每小時取樣 → +30 min）
  • 式 (7.1)：G₂₁ 延遲 5 → 35 min、G₂₂ 延遲 0.1 → 30.1 min；負荷列（G₁₁、G₁₂）不變
  • 效果：負荷約 1 小時收斂、細度標準差趨近零、控制器權重維持名義值，僅調整一次

機制解釋（對應 Table 7.1，紙本 p.142）：修改模型延遲會改變 FIR 係數與預測計算，進而改變 QP 的 Hessian；同時改變估測器回授的偏差項。因此「改模型」即可吸收慢速量測，不需重新整定權重。

引用注意：原文把「每小時取樣」「樣本化驗後輸入」「細度更新延遲一小時」混用，未拆分取樣間隔、物料傳輸延遲與化驗延遲各自的數值；本章也未給出控制器的實際運算週期（Ch.6 實廠的「每分鐘執行」不能套用到本章）。「+30 min」是模型修正的經驗法則，不是對實際延遲組成的宣稱。

08批判性評估：證據的強度與缺口

  1. 「穩健」是模擬與實驗觀察，不是形式化證明。全書沒有軟約束 MPC 的穩健穩定性（robust stability）數學證明；標題的 Robust 應理解為工程意義上的失配容忍。
  2. 容忍度數字不可外推。§3.8 的 40%/50%/2× 來自特定 SISO 參數案例（如延遲 5→3 或 7 其實是 ±40% 案例、增益 1→2 是 +100%）；不能推論所有參數方向或 MIMO 組合「大於 50% 失配仍穩定」。摘要中「mismatch more than 50% 時傳統 MPC 振盪、軟 MPC 穩定」的說法僅對應部分展示案例。
  3. 50% 宣稱與正文數據口徑不一致（見 6.1 節），且實廠 23% 缺少原始數據佐證。
  4. 雜訊尺度前後不一致：Ch.4 不同段落分別出現 0.01 與 0.01²（變異數 vs 標準差易混淆）。
  5. 變數方向筆誤：摘要與 Ch.8 各有一處把 MV/CV 寫反，閱讀時以 Ch.5/6 為準。
  6. 方法定位：MHE（§3.5）是理論貢獻與 SISO 驗證，並未進入水泥磨實作；水泥磨章節使用的是簡易估測器。把整本論文概括為「MHE-based MPC 上廠」是不正確的。
  7. 實作時代背景：求解器為作者自寫的 MATLAB 內點法（附錄 D/E），以 CEMulator/ECS 平台整合。今日讀者應關注其問題建模（FIR＋軟帶＋半取樣延遲規則），而非程式碼本身的工程價值。

10術語表

術語說明
MPC（模型預測控制）每個取樣時刻以模型預測未來輸出、求解有限視界最佳化，只執行第一步，下一時刻重算（receding horizon）。
MV / CV / DV操縱量（控制器可調）／受控量（要維持目標）／擾動變數。本論文 DV 主要是熟料易磨性。
FIR 模型有限脈衝響應模型：輸出 = 過去 n 個輸入的加權和（權重 Hi 為馬可夫參數）。只需安定時間即可建立，適合缺漏量測，但僅限穩定系統。
SOPDT with zero二階加純延遲且含零點的轉移函數，水泥磨辨識所得模型形式（式 5.1）。
簡易估測器把預測誤差累積成偏差項 b̂，等效積分作用，消除穩態偏移（式 3.9）。
MHE（移動視窗估測）在歷史視窗上把未知擾動序列當決策變數求解的估測器（式 3.14），可加約束但計算量大。
